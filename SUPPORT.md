# Support

## Community support

Before requesting help:

1. Read the package README and the executable SampleProjectManagement examples.
2. Search existing issues for the error or affected public symbol.
3. Verify the problem against a supported package version.

For reproducible defects, open a GitHub issue and include the package version,
.NET or Node version, database provider where relevant, a minimal reproduction,
expected behavior, actual behavior, and sanitized logs. Never post credentials,
customer data, private URLs, or full production configuration.

Questions without a reproduction may be redirected to a discussion channel
when one is available. Community support is best effort and does not include a
service-level agreement.

## Security and commercial support

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
For commercial support, implementation assistance, or contractual service
levels, contact `info@newheap.com`.
