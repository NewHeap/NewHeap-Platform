# v9.0.0

## NewHeap.Platform.AI.Common: per-tenant tool concurrency

The default in-process tool concurrency limiter keeps a separate `MaxConcurrency`
bound per tool and `NhAiInvocationContext.TenantId`. A tenant that fills a tool's
bound no longer causes other tenants' calls to be refused with
`ai-tool-concurrency-limited`. Invocations without a tenant share one bound, so
single-tenant hosts keep their behavior. Configure the partition with
`UseInProcessConcurrencyLimiter` and `NhAiToolConcurrencyPartition`.

| Breaking change | Required action |
| --- | --- |
| Multi-tenant hosts on the default limiter admit `MaxConcurrency` calls per tenant instead of per process. | Where the bound protects a resource that every tenant shares, call `UseInProcessConcurrencyLimiter(options => options.Partition = NhAiToolConcurrencyPartition.Tool)`. |
