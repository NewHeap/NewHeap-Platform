# v1.4.0

## @newheap/platform-common: two-factor authentication

`BaseNhAuthService` covers the two-factor flows of `NewHeap.Platform.AspNet.Common`:
challenges, required enrollment, e-mailed codes, remembered devices, passkeys through
`NhPasskeyClient`, account settings and administration. The optional
`@newheap/platform-common/two-factor` entry point adds standalone challenge,
enrollment, recovery-code, settings and passkey sign-in components with English and
Dutch texts. Applications that do not import the entry point ship none of its code.

| Adoption note | Required action |
|---|---|
| `authenticate` fails with `two-factor-required` or `two-factor-enrollment-required` instead of storing a pending step. | Use `authenticateInteractive` with the verify or enrollment methods before enabling two-factor authentication on the server; no action otherwise. |
| The enrollment QR code is a PNG data URI. | Allow `img-src data:` in the content security policy of pages that show the enrollment or settings components. |
