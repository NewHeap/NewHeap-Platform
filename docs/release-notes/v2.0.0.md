# v2.0.0

## @newheap/platform-common: texts for regional languages

The texts of the two-factor components (`nh-two-factor.`) also reach a host language with a region:
`nl-NL` and `nl-BE` receive the Dutch texts and `en-GB` the English ones, where every language other
than `en` and `nl` received English before. A host that merged the `nl` bundle into its regional
language itself can remove that merge; keys the host defines under `nh-two-factor.` still win.

| Breaking change | Required action |
|---|---|
| A host language such as `nl-NL` receives the Dutch texts instead of the English ones. | None; remove your own merge of the bundles into regional languages if you have one. |
