# v1.3.0

## @newheap/platform-common: background-operation administration

Angular consumers call the background-operation administration endpoints of
`NewHeap.Platform.AspNet.Common` through `NhBackgroundOperationAdministrationService`.

| Adoption note | Required action |
|---|---|
| Administrator actions add the `background-operation.administrator-cancellation-requested` and `background-operation.administrator-retry-requested` events, and operator-only events use `nh-background-operations.operator-only`. | Add these keys to the application translations. |
