# NewHeap.Platform.Common.Test

Reusable test helpers for applications that consume `NewHeap.Platform.Common`.
The package provides validated dependency-injection test contexts, `TaskResult`
assertions and NSubstitute predicate helpers.

This is a support library, not the location of NewHeap Platform's own regression
tests. Library self-tests live in the non-packable
`src/Back-end/Tests/NewHeap.Platform.Common.Tests` project.
